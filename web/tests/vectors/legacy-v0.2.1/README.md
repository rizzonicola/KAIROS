# Frozen parity vectors (KAIROS v0.2.1)

These JSON files were generated by the Python reference implementation that
shipped with KAIROS v0.2.1 (`scripts/export_web_vectors.py`, now removed). They are
**frozen**: nothing regenerates them any more.

| File | Still enforced? | Against what |
|---|---|---|
| `parse_info.json` | yes | `parseInfo` (TypeScript) |
| `postures.json` | yes | `postures.ts` (weights, inference, hysteresis, fragility, variety) |
| `guards.json` | yes (`resultBand`, `saturation`, `supported`) | `guards.ts` |
| `guards.json` (`repetition`, `fiftyMove`) | yes, via the core | `KairosCore.repetitionCount` / `resetsHalfmove` (see `tests/vectors.test.ts`) |
| `probes.json` | yes | `probeFeatures` |
| `board.json` | partly: FEN-after-move, halfmove reset, captured value, check | core conformance test (needs the WASM build) |
| `features.json` | **no, intentionally** | the old values came from static proxies; see `docs/FEATURES_CHANGELOG.md` |

The enforced v0.3 feature fixture is `web/tests/vectors/v0.3/features.json`, generated from the Rust/WASM
core and checked by `web/tests/core.test.ts`.
